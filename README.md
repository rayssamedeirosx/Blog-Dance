# Blog Dance!

## Sobre a página

O Blog Dance foi criado para apresentar um pouco do universo da dança de forma simples e interessante. Nele são compartilhadas informações, dicas e curiosidades relacionadas à dança e à rotina dos bailarinos.

A página conta com postagens acompanhadas de imagens, um vídeo sobre o tema e botões de interação para que o usuário possa reagir aos conteúdos.

## Desenvolvimento

Para a construção do blog foram utilizados HTML, CSS e JavaScript. O HTML organiza os elementos da página, enquanto o CSS é responsável pelo estilo e pela organização visual. Já o JavaScript permite o funcionamento dos botões de curtida.
